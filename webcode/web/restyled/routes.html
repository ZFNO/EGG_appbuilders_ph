no backend · fetch shim intercepts /api/*

Static file routes — served by serve.mjs

The app ships with no backend. serve.mjs only serves these files; the friendly paths (/, /guide, /scope, /routes) map onto the matching .html. Everything else is served from disk; a missing file is 404, and any /api/* that reaches the server (the shim should have caught it) is 501.

API routes — in-browser fetch shim (never hits the network)

These mirror the FastAPI routes in server.py. They are handled inside the page by api.js, which intercepts fetch("/api/...") and runs the request against the in-browser engine. Bodies and query params are parsed the same way.
