Get started

Four guided steps from "what is this?" to "I've handled something". Each panel shows exactly what Egg does with your words. The first three are automatic; the last one is where you decide.

01

Type one plain-language request

No syntax, no menus. Write it the way you'd hand it to an assistant — one ask per message.

Tip: a Capitalised name after "with" / "to" / "for" names the party; a YYYY-MM-DD date sets the deadline.
>
intent: follow_up party: Acme risk: R3
02

Egg reads what matters

It pulls out the intent, the party and any deadline, and scores how risky the job is (R1 routine → R3 consequential).

Unsure? It comes back needs clarification rather than guessing.
Follow up with Acme supplier by 2026-10-12
  • party: Acme
  • deadline: 2026-10-12
  • intent: follow_up
03

It routes to a capability

The router hands the job to the one node that knows how to do it — a follow-up, a schedule change, or a queue.

Low-risk routine work can run straight through; the risky kind stops at the gate.
?Request
RRouter
NNode
04

You approve — then it acts

Sending, paying, deleting or committing pauses here. You see the exact payload; approving runs the node once, with that exact payload.

Change the payload and the old approval is void — a fresh yes is required.
