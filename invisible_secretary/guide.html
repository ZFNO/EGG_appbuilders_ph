Guide - the same dashboard, described in place

Each functional element below carries its own description. Elements marked LLM are the only place the on-device model is used; everything else is deterministic. Runtime is local; all integrations are mocks labelled SIMULATED.

Tell it what needs handling uses the LLM

Accepted input: free text, one request per message. There is no command syntax — the model reads intent + parameters from your words.

Try one of these — click to load it into the box:
What it reads from your text
• party — a Capitalized name right after with / to / for, e.g. with Acme
• deadline — a date written as YYYY-MM-DD, e.g. 2026-10-12
• everything else is free text — keep it to a single ask per message
× won't do on purpose: pay / purchase / delete / refund / legal / hiring — these come back rejected.
Unclear or too vague? It asks you to clarify rather than guess. Free-text only — there is no fixed command syntax.

Your free text is the model's only input (POST /api/route). Clicking Route runs bounded classification: rules first, the on-device Qwen model enhances (fills parameters, agrees, or abstains on disagreement). The model never picks the node, sets urgency, authorizes, or executes.
